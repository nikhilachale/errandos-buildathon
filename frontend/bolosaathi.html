Under the hood

How the native-language loop actually works

BoloSaathi handles orchestration and confirmation. Sarvam handles turning speech into text and text back into speech, in the person's own language.

Input

User voice

Spoken in Hindi, Tamil, Bengali or another supported language, code-mixed or not.

→
Sarvam

Language intelligence

Saaras v3 transcribes speech; Translate and language ID normalize the text.

→
Orchestration

BoloSaathi MCP

Plans the task, requests confirmation, and calls the right tools.

→
Execution

Connected services

Grocery, cab, and other MCP-compatible services carry out the task.

→
Sarvam

Voice response

Bulbul v3 speaks the result back naturally, in the same language.

Sarvam is a language-technology partner in this loop, not an endorser of BoloSaathi. No claims of official partnership are made.

For developers & technical caregivers

Install the MCP server

Six steps from a clean machine to a working voice-first assistant. Replace placeholder values with your own before running these commands.

Before you start

You'll need the following on the machine that will run the MCP server:

  • ✓ Node.js 20 or later, or Python 3.11 or later (depending on the distribution you choose)
  • ✓ An MCP-compatible client (a configurable chat or agent tool) to connect the server to
  • ✓ A Sarvam API key for speech and language processing
  • ✓ Credentials for any service you want BoloSaathi to connect to, such as a grocery or cab provider

Install the package

Install the server globally, or into a project, using your package manager of choice.

npm install -g @bolosaathi/mcp-server

Set your environment variables

Create a .env file (or export these directly) with your own values in place of the placeholders below.

SARVAM_API_KEY=your_sarvam_key BOLOSAATHI_DEFAULT_LOCALE=hi-IN BOLOSAATHI_CONFIRM_TIMEOUT_SECONDS=30

Add it to your MCP client

Add BoloSaathi as an MCP server in your client's configuration file, using the command from step 2.

{ "mcpServers": { "bolosaathi": { "command": "bolosaathi-mcp", "args": ["--locale", "hi-IN"] } } }

Try your first request

Restart your MCP client, then speak or type a plain request to check the connection.

"Mujhe kal shaam 6 baje ek cab book karni hai station ke liye."

BoloSaathi should respond by reading back the plan and asking for confirmation before booking anything.

If something isn't working

  • ! No response at all — check that your MCP client has fully restarted after editing its configuration.
  • ! Speech isn't recognized correctly — confirm SARVAM_API_KEY is set and the locale matches the language being spoken.
  • ! Requests never ask for confirmation — check that the connected service's plugin reports actions as sensitive; this is what triggers the confirm step.
  • ! A connected service fails — verify its own credentials separately; BoloSaathi surfaces that service's error rather than masking it.
